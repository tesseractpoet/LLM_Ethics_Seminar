# LLM_Ethics_Seminar
A set of applied ethics case round-tables &amp; practicum cases you can teach a LoRA, assembled by me and Claude Opus 5.5, using public domain &amp; common-knowledge case studies, with some fictional agentic scenarios.  LoRA training produces a change in behavior. Is the robot smarter or just more anxious? (Created for Swarm Alignment Hackathon 2026.)
